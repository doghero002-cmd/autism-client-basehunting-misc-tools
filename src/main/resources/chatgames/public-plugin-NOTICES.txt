Commit: f45eca102b36daf3357dd27a7a9795ac261ef1b1

Seventeen questions and 35 word targets are selected. One valid accepted answer
is retained for multiple-answer questions. The hunger question uses steak, not
the source's incorrect golden-carrot alternative. Bat leather, fixed spawn
blocks, a chest made from a chest, and misleading block/tool questions are
excluded. These selected targets are not a copy of the entire default pack.

The RareHyperIonYT entries use named answers for free-text questions, not the
upstream multiple-choice letters. The language question assumes Java Edition,
as does this addon. Historical version answers preserve the upstream version
family labels, not exact patch versions. Obsolete counts and ambiguous entries
were omitted. Questions with multiple accepted answers use one accepted answer.
